## 1. 能不能按步进频雷达的方式，把呼吸、挥手、跳跃分开？

可以。一次 IPT 测量是慢时间上的一个采样，内容是频率轴上的复数信道响应 `H(f) = I + jQ`。对频率做 IFFT 之后，纵轴才是快时间；再按双程相位换成距离 `R = cτ/2`。多帧叠起来就是距离-时间图。

需要改的两点：

- IFFT 之前的那一维是信道频率，不是快时间。
- 这条记录的带宽大约 74 MHz，双程距离分辨率约 2.0 m。呼吸、挥手、跳跃都落在约 2.7 m 的同一个主瓣里，不会沿距离轴走动。差别在主瓣里的快慢和强弱。

这条文件的帧间隔中位数是 30.0 ms，慢时间采样率 33.33 Hz。`seq` 基本每次加 2，和「步进 15 ms、每两步记一帧」一致，不是 50–66 Hz。每帧只有本地 I/Q，相位按双程处理。每帧大约 51 个 tone，缺测先沿慢时间补上再做 IFFT。

作图窗口从每个 event 后再空 5 s，取 16 s：慢速呼吸 5.0–21.0 s，上下挥手 78.4–94.4 s，上下跳跃 130.0–146.0 s。

主峰单元上：呼吸的位移谱峰 0.19 Hz，挥手 1.69 Hz，跳跃 0.31 Hz。跳跃的残留幅度大约是呼吸的 3 倍。厘米量级的位移是主峰相位被强静止径稀释之后的等效值，不是胸口或手的真实幅度。

## 2. 距离-多普勒图和快慢时间图有什么区别，有什么用？

两张图用的是同一批距离剖面，纵轴都是双程距离。距离-时间图的横轴仍是秒，保留动作在这 16 s 里怎么展开。再沿慢时间做一次 FFT，横轴变成多普勒频率，就得到距离-多普勒图：这段里有哪些节奏、各自多强，但第几秒发生不再分开。

这次数据上：

- 距离-时间图里，呼吸是慢亮带，挥手是细竖条，跳跃是几团亮块。
- 距离-多普勒图里，呼吸聚在 ±0.19 Hz，挥手的快分量在 ±1.69 Hz，跳跃又亮又宽。
- 呼吸和挥手的残留幅度接近，共用色标时距离-时间图都偏暗，要靠多普勒或位移谱把 0.19 Hz 和 1.69 Hz 分开。
- 跳跃的谱峰 0.31 Hz 落在呼吸频段里，单看频率会和呼吸混在一起；距离-时间图上的亮块和大约 3 倍的残留幅度才能把它分开。

要读节奏，用距离-多普勒，主峰切一刀的频谱就够。要看动作是持续的还是突了几下，用距离-时间图。

## 3. 多普勒的负频率有什么意义？只看正频率够不够？

来回动的时候，正频率就够用来读节奏。负频率表示相反的径向方向。

距离单元上的慢时间信号是复数，正频率和负频率可以一边强、一边弱。原地往返（呼吸、挥手、跳跃）一个周期里两个方向各走一遍，谱线上就是 ±f 一对。慢速呼吸的 −0.188 Hz 和 +0.188 Hz 幅度比约 1 : 0.88，节奏就是 0.19 Hz。

只有单向靠近或远离时，能量才会主要堆在一侧。这次呼吸两侧几乎一样，没有这种单向成分。相位的正负还没有用一次已知的靠近或远离标定过，所以左右先只看成两个相反方向。

位移谱来自实数波形，只画 0 Hz 以上。正半轴到奈奎斯特频率 16.7 Hz 为止。这次最快的有用分量是挥手的 1.69 Hz。

## 4. 频谱相关的图上，那条把图平分的虚线是什么？

那是青色虚线，标静态主峰的距离，大约 2.7 m。它横着穿过每一幅距离-时间图和距离-多普勒图，表示不动的时候能量聚在这个距离上。

它看起来把图上下平分，是因为纵轴按这个主峰上下各留 6 m 来裁，主峰落在画面中间。线的位置是测出来的距离，不是正负频率的分界。

距离-多普勒图正中另有一条很淡的白色竖线，那一条才是 0 Hz：左边负多普勒，右边正多普勒。动作的能量都贴着青色横线，说明没有换到别的距离单元。
